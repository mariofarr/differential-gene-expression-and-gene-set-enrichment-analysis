## README

### Overview

We used RNA-seq data from cell lines treated and untreated with Neutrophil Extracellular Traps (NETs) and performed a differential gene expression analysis with DESeq2 to identify important gene expression differences related to treatment.\
Next, we performed a gene set enrichment analysis to assess the key biological processes regulated in response to treatment. The data were obtained from the GEO repository and are publicly available under the code GSE218119 or at (<https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi>)

### Dataset Description

The dataset contains RNA-seq data from murine breast cancer cell lines of the species *Mus musculus* (410.4) in the presence and absence of NETs. Each condition has 3 replicates, which are:

-   VEH1 (untreated)

-   VEH2 (untreated)

-   VEH3 (untreated)

-   NET1 (treated)

-   NET2 (treated)

-   NET3 (treated)

### Objectives

-   Identify the differentially expressed genes between treatment conditions;

-   Visualize the results of the differential expression with a volcano plot;

-   Investigate the pathways that were modulated in response to treatment with enrichment analysis.
